# iPhone experience — 27 октября 2026

## Реализовано

- Отдельные native-стили: системный шрифт, светлая/тёмная тема iPhone, безопасные отступы, адаптация маленьких экранов и увеличенного текста. Веб-дизайн сохранён.
- Нижние вкладки с короткими подписями; в уроке и при открытой клавиатуре они скрыты. При переходе между экранами прокрутка начинается сверху. Разрешён системный жест возврата WebView и интерактивное закрытие клавиатуры.
- При первом запуске native UI использует предпочтительные языки iPhone: uk/ru/sk/en, для остальных — en. Ручной выбор сохраняется на устройстве, включая экран входа. Учебный контент продолжает использовать свои переводы и предусмотренный fallback.
- Настройки звука и haptics применяются и сохраняются сразу. Тактильный отклик подключён к ответам и завершению урока; его можно отключить независимо от звука.
- Нативный запрос разрешения уведомлений, отображение фактического разрешения iOS, переход в системные настройки при запрете и кнопка тестового уведомления через 5 секунд.
- Локальные напоминания по времени iPhone с локализованным текстом и calendar-триггерами. План на 30 дней обновляется при запуске, возврате в приложение, смене языка/времени/аккаунта и после практики. Занятие сегодня убирает напоминание на сегодня. При отключении или выходе собственные запланированные уведомления удаляются.
- В сборке для телефона нет зависимости от Google Fonts: интерфейс использует системный шрифт.

## Удалённые push: подготовлены, пока выключены

Разработка продолжается с Personal Team. В обычной сборке `IOS_PUSH_ENABLED` выключен: локальные напоминания работают независимо от удалённых push. Доставку через APNs без платного Apple Developer не проверяли.

Подготовлены регистрация APNs в AppDelegate, клиентский жизненный цикл токена, защищённый endpoint `/user/native-push-token`, отдельная таблица `native_push_tokens` и расширение существующей административной рассылки на APNs. Токен привязан к сессии пользователя; отключение удаляет только его регистрацию, смена аккаунта переносит устройство, удаление аккаунта очищает токены. APNs-токены не передаются в Firebase как FCM-токены.

После активации Developer Program:

1. В Apple Developer включить Push Notifications для `sk.slovakgo.app` и обновить профиль подписи. Выбрать соответствующую Team в Xcode.
2. Включить Push Notifications в Signing & Capabilities. Подготовленный файл — `ios/App/App/Push.entitlements`. Для Debug можно добавить в игнорируемый `ios/Signing.local.xcconfig`:

   ```xcconfig
   CODE_SIGN_ENTITLEMENTS = App/Push.entitlements
   APS_ENVIRONMENT = development
   ```

3. Создать APNs authentication key. Настроить **только на сервере**: `APNS_KEY_ID`, `APNS_TEAM_ID`, `APNS_PRIVATE_KEY` (содержимое .p8), `APNS_TOPIC=sk.slovakgo.app`. Ключ не хранить в репозитории или VITE-переменных.
4. Развернуть обновлённый API с endpoint регистрации и APNs transport до включения push в приложении. В этой задаче production API не развёртывался.
5. Для Debug выполнить `IOS_PUSH_ENABLED=1 IOS_PUSH_ENVIRONMENT=sandbox npm run ios:sync`. Для TestFlight/App Store нужны production-профиль, `aps-environment=production` и `IOS_PUSH_ENVIRONMENT=production`.
6. На отдельном тестовом аккаунте проверить регистрацию, доставку, нажатие уведомления, запрет в Settings, выход и смену аккаунта. Не использовать массовую рассылку как smoke test.

## Повторить UI-проверку

`IOS_UI_TEST=1 npm run ios:sync` собирает изолированный сценарий с локальными данными и перехваченными API-запросами. Он не должен устанавливаться на физический телефон. XCTest-сценарии находятся в `ios/App/AppUITests/IPhoneExperienceTests.swift`.

После UI-тестов **обязательно** выполнить `npm run ios:sync` без `IOS_UI_TEST`, затем пересобрать устройство в Xcode. В обычной сборке тестовые данные и перехват запросов отсутствуют. `testPhysicalPhoneLaunch` — отдельный сценарий только запуска/снимка без изменения аккаунта; остальные сценарии предназначены для fixture-сборки Simulator.

Источники: [Capacitor Local Notifications](https://capacitorjs.com/docs/apis/local-notifications), [Capacitor Push Notifications](https://capacitorjs.com/docs/apis/push-notifications), [Apple APNs requests](https://developer.apple.com/documentation/usernotifications/sending-notification-requests-to-apns).
